# ISS Pass Predictor · London

ISS pass predictor for London, with a live day/night ground-track map.

## How to use

Double-click **`index.html`** (or drag it into Chrome or Safari). Nothing to install.
It pulls the ISS position and orbit live from wheretheiss.at and CelesTrak, so it needs internet.

## Files

- `index.html`: the whole app (HTML, CSS and JavaScript in one file)
